# LUMIN — competition development report

This folder contains a standalone GitHub Pages website and an editable Markdown development report.

- `index.html`: designed static report website.
- `REPORT.md`: editable Markdown report.
- `assets/`: real-world browser screenshots supplied for LUMIN v1–v4, converted to lightweight WebP.

## Publish

1. Replace `https://YOUR-USERNAME.github.io/LUMIN/` in `index.html` and `REPORT.md` with the real artwork URL.
2. Upload `index.html` and the entire `assets` directory to a new GitHub repository root.
3. Open **Settings → Pages → Deploy from branch → main / (root)**.
4. Link back to this report from your existing LUMIN site or dashboard.

The report does not include a v5 screenshot or claim a winner over Claude.
